# 智能文件统计与报告系统

## 项目概述
这是一个为企业培训、项目协作等场景设计的**文件夹内容盘点工具**。它能够一键扫描指定目录下的所有文件夹，**深度统计文件数量、类型分布，并自动生成带有可视化样式和多维度分析的Excel数据报告**。本工具专为需要定期汇总文件资产、分析文档构成的团队运营者设计。

## 核心价值：解决什么业务痛点？
- **痛点**：在培训或项目管理中，散落在数十个甚至数百个个人文件夹中的文件（如作业、报告）无法快速统计。人工盘点耗时耗力、容易出错，且无法获得类型分布、集中度等分析视角。
- **解决方案**：本系统通过自动化脚本，**在几分钟内完成原本需要数人日的盘点工作**，输出包含“总量统计”、“详细清单”和“汇总分析”三张工作表的专业报告，为管理者提供精准的数据决策支持。

## 效果与数据（量化价值）
- **效率提升**：将文件盘点与统计工作的效率提升**数百倍**。例如，盘点一个包含100个学员文件夹、每个文件夹含若干子目录的项目，手动需1-2天，本工具可在**1-2分钟内**完成并生成报告。
- **统计维度丰富**：不仅统计总数，更按 **13种常见文件类型**（Word、Excel、PDF、图片、代码等）自动分类，并提供子文件夹维度分析。
- **报告专业化**：直接产出**可直接用于汇报的Excel文件**，内置配色、自动列宽、重点数据高亮等样式，节省额外美化时间。

## 技术栈与实现原理
- **语言**：Python 3
- **核心库**：
  - `pandas`: 进行数据结构化处理和Excel写入的核心。
  - `openpyxl`: 用于生成和深度美化Excel文件（设置样式、字体、颜色、边框）。
  - `os`, `collections`: 用于递归遍历文件系统、计数和分类。
- **核心逻辑**：
  1.  **递归扫描**：遍历运行目录下所有第一层“主文件夹”，并深入其子文件夹。
  2.  **智能分类**：根据预定义的13类文件扩展名映射表，将文件智能归类。
  3.  **双维度统计**：分别统计每个“主文件夹”下，各个“子文件夹”内的文件，以及“主文件夹”根目录下按类型归类的“其他文件”。
  4.  **三层报告生成**：
      - **文件夹统计表**：矩阵式数据，清晰展示每个主文件夹在各子文件夹/文件类型下的数量。
      - **文件清单表**：记录每个文件的具体路径和归属，便于溯源。
      - **汇总分析表**：提供如“平均文件数”、“最常见文件类型”等深度洞察。
  5.  **自动美化**：应用预设的报表样式，提升报告可读性与专业性。

## 快速开始
1.  **安装依赖**：`pip install -r requirements.txt`
2.  **放置脚本**：将此脚本放置在你需要统计的**所有主文件夹的上一级目录**中。
3.  **运行脚本**：双击运行 `main.py`，或通过命令行运行 `python main.py`。
4.  **获取报告**：程序运行后，将在同目录下生成名为 `文件夹统计报告_YYYYMMDD_HHMMSS.xlsx` 的文件。

## 使用场景
- 培训运营：定期统计学员提交的作业、报告总数与类型分布。
- 项目协作：盘点各成员贡献的文档、设计稿、代码文件数量。
- 数字资产管理：对任何复杂的目录结构进行快速资产清点和分类分析。
